## 🗺️ Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MANSI-cse/Citizen-Complaint-and-public-service-Portal.git
   ```
2. **Install dependencies** (if full stack):
   ```bash
   cd Citizen-Complaint-and-public-service-Portal
   npm install
   # or for the backend/frontend as appropriate
   ```
3. **Run the app:**
   ```bash
   npm start
   ```
   or use specific frontend/backend scripts as needed.
4. **Open in browser:**
   ```
   http://localhost:3000
   ```
   (Update with your running port)

---

## ✍️ How it Works

1. **Citizens submit complaints**—optionally using voice input and attaching images.
2. **AI engine summarizes the complaint** for faster authority triage.
3. **Complaints are categorized (urban/rural)** and assigned to the right department.
4. **Authorities manage, update, and resolve issues** through an admin dashboard.
5. **Citizens track the status** of their complaints in real time.
